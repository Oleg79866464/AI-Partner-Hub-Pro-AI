# AI Catalog RU

Production-ready Russian AI tools directory for marketers and content creators.

## What is included
- Next.js 14 App Router homepage with server-side filtering
- Supabase PostgreSQL schema for tools, clicks, and analytics
- Python parser for `taaft.json` and a Supabase import helper
- Click tracking redirect endpoint
- Protected admin dashboard and CSV export
- Dynamic sitemap, robots.txt, metadata, and schema.org markup

## Environment variables
Copy `.env.example` to `.env.local` and fill in:

- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`
- `SUPABASE_SERVICE_ROLE_KEY`
- `ADMIN_SECRET_KEY`
- `NEXT_PUBLIC_SITE_URL`

## Deployment steps

### 1. Parser
```bash
cd parser
python3.11 -m venv venv
source venv/bin/activate
pip install pydantic==2.5.3 requests==2.31.0 beautifulsoup4==4.12.3
python parser.py
```

The parser reads `taaft.json`, validates tools, writes `tools_clean.json`, and logs parsing issues to `parsing_errors.json`.

To import the cleaned data into Supabase, run:

```bash
cd parser
python3.11 -m venv venv
source venv/bin/activate
pip install supabase==2.6.0
python import_to_supabase.py --input tools_clean.json
```

### 2. Supabase
1. Create a Supabase project.
2. Open the SQL editor.
3. Run `db/schema.sql`.
4. Import `parser/tools_clean.json` into the `tools` table or run `python parser/import_to_supabase.py --input tools_clean.json`.

### 3. Next.js
```bash
npm install
cp .env.example .env.local
npm run dev
```

For production deploy:

```bash
vercel --prod
```

## Monetization logic
We do not use CPC $0.05 clicks.

Revenue estimate formula:

```text
estimated_revenue = clicks × conversion_rate (0.15) × avg_product_price ($29) × commission_rate
```

Example:

```text
1000 clicks × 0.15 × $29 × 0.20 = $870/month
```
